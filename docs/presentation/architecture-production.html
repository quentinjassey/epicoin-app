Choix Cloud vs On-premise — Justifié 08 · Décision infrastructure

Cloud souverain UE Choisi

AWS Paris (eu-west-3) + Supabase Frankfurt
  • RGPD : données hébergées en UE, sous juridiction européenne (conforme hébergement données bancaires art. L.312-1 CMF).
  • Certifications héritées : PCI-DSS L1, SOC 2 Type II, ISO 27001 (évite un audit full-stack interne).
  • Scalabilité élastique : pics rentrée Sept (×3 volume) absorbés sans surprovisionnement.
  • OPEX < CAPEX : pas d'investissement matériel initial, pay-as-you-go aligné sur la croissance users.
  • Haute dispo native : multi-AZ, RTO < 5 min, SLA 99,99 % cible atteignable.
  • Équipe réduite (5–7 pers.) : pas de sysadmin dédié, IaC via Terraform + managed services.

On-premise / Colocation Écarté

Datacenter propre ou baie louée OVH/Scaleway bare-metal
  • CAPEX initial 80–150 k€ (serveurs, HSM, firewall, licences) — incompatible budget MVP.
  • Certifications PCI-DSS / SOC 2 à obtenir en propre : +6–12 mois, +50–100 k€/an audit.
  • Recrutement DevOps / SecOps dédié (2 ETP minimum) pour maintenance 24/7.
  • Élasticité limitée : dimensionnement pic = surcoût matériel permanent.
  • Plan de reprise d'activité (PRA) à concevoir, tester, maintenir en interne.
  • Pertinent uniquement si > 500 k users OU exigence souveraineté stricte (OIV, défense).
Verdict — Cloud managé UE retenu pour Phase 3. Hybridation envisagée Phase 4 (> 100 k users) : HSM dédié on-premise pour clés cryptographiques + Cloud pour le reste. Pas de vendor lock-in dur : IaC Terraform portable, base PostgreSQL standard.
